1. Algebra: Important Identities

Algebra uses symbols such as x and y to represent numbers.

(a + b)² = a² + 2ab + b²

(a − b)² = a² − 2ab + b²

a² − b² = (a − b)(a + b)
Example: x² − 9 = x² − 3² = (x − 3)(x + 3).

2. Functions: Domain and Range

A function f:A→B assigns each input in A exactly one output in B.

  • Domain: allowed inputs.
  • Codomain: target set of outputs.
  • Range: outputs the function actually attains.
Example: For f(x)=x² with domain ℝ, the range is [0,∞), because every real square is non-negative.

3. Limits: Basic Idea

lim(x→a) f(x)=L means f(x) approaches L as x approaches a, when the limit exists.

lim (x → a) x² = a²
Example: lim(x→2)(x²+1)=2²+1=5, by direct substitution for a polynomial.
The value f(a) and the limit at a are related, but they are not always equal.

4. Derivatives: Power Rule

A derivative describes the instantaneous rate of change of a function, where it exists.

d/dx (xⁿ) = n xⁿ⁻¹
Example: If f(x)=x³, then f′(x)=3x².

5. Real Analysis: Supremum and Infimum

Let S be a non-empty subset of ℝ.

  • An upper bound u satisfies x≤u for every x∈S.
  • The supremum sup S is the least upper bound.
  • A lower bound l satisfies l≤x for every x∈S.
  • The infimum inf S is the greatest lower bound.
Example: For S=(0,1), sup S=1 and inf S=0. Neither endpoint belongs to S.
The supremum need not belong to the set. If it does, it is also the maximum.

6. Sequences and Convergence

A real sequence is commonly written (aₙ). It converges to L if for every ε>0 there is N∈ℕ such that n≥N implies |aₙ−L|<ε.

Example: aₙ=1/n converges to 0 as n→∞.

7. Practice Questions

Q1. Find sup S for S={x∈ℝ: 0<x<4}.

Show answer

sup S=4. Values in S can approach 4, but 4 is not in S.

Q2. Differentiate f(x)=x⁴.

Show answer

f′(x)=4x³, by the power rule.

Q3. What is the range of f(x)=x² for x∈ℝ?

Show answer

[0,∞).
